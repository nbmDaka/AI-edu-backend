# Локальный прототип Audio2Face

Исходники нашего viewer, потокового OpenAI-шлюза и NVIDIA-worker. Это отдельный локальный прототип, не сервис production. Стандартный Docker Compose платформы его не запускает. При `NODE_ENV=production` Node-сервисы отказываются запускаться; слушают только 127.0.0.1.

## Что входит

- OpenAI генерирует потоковый текст по контексту текущей лекции и речь Ash, PCM 24 кГц.
- `audio2face-stream.py` запускается внутри NVIDIA Kit. Mark и blendshape-solver вычисляют лицевые веса с акустическим контекстом 300 мс.
- `stream-gateway.cjs` отправляет сегменты PCM и веса через авторизованный SSE. Обслуживается один запрос, остальные получают занятость. Отмена освобождает GPU-сессию.
- Three.js viewer воспроизводит звук и лицевые веса по одному таймеру, сглаживает начало и конец речи, обрабатывает остановку и переполнение/недостаток буфера.
- Камера закреплена. Процедурные жесты руками отключены после проверки пользователем; приветствие использует небольшой кивок. Прототип жестов не прошёл проверку естественности и не должен включаться вместо готовой анимации.

Это фразовый поток TTS, не OpenAI Realtime speech-to-speech. Непрерывный микрофон, VAD и прерывание речи реализованы в frontend и включаются только в локальном режиме аватара.

## Чего здесь нет

Модель Кевина из CC Trial, текстуры, образцы реальной речи, NVIDIA runtime, нейросетевые веса, ключи, пользовательские данные и кэш не публикуются. Модель предоставляется отдельно с подходящей лицензией. Подключение модели требует морфов из `a2f-cc-map.json`, существующий рендер настроен под локальный экспорт Кевина. Для другого персонажа нужны отдельные настройка и проверка.

Прототип проверен с Audio2Face 2023.2 на Windows и NVIDIA GPU. Перенос на Linux, массовое использование, очереди, квоты и серверная безопасность не проверены. Не включайте DEBUG на внешнем Django ради аватара.

## Запуск

Нужны Node.js 24, установленный отдельно Audio2Face 2023.2 и приватный GLB. Все крупные данные и кэш можно держать на E:. Не копируйте их в Git.

1. В этой папке выполните `npm ci` и настройте локальный `.env` по `.env.example`. `AVATAR_STATE_DIR` должен совпадать у Node-процессов и Kit. `API_SHARED_KEY` совпадает с `AI_SERVICE_API_KEY` Django. Настоящие ключи находятся только в локальном окружении.
2. Запустите Kit из PowerShell с теми же путями:

```powershell
$env:A2F_INSTALL_DIR='E:\private-avatar\audio2face-2023.2.0'
$env:AVATAR_STATE_DIR='E:\private-avatar\state'
.\start-audio2face.ps1 -Streaming
```

3. Дождитесь `stage=ready` в `AVATAR_STATE_DIR/stream/status.json`. Приватный ключ solver автоматически создаётся в `stream/key.txt`. Не открывайте наружу порты worker; встроенный публичный gRPC-listener отключается при инициализации streaming-сцены.
4. В двух терминалах выполните `npm run viewer` и `npm run gateway`. Viewer доступен на `http://localhost:5184/`, SSE-шлюз - на 127.0.0.1:5185. Порт solver - 8012, REST NVIDIA - 8011.
5. Локальный Django: `DEBUG=true`, `AI_AVATAR_SERVICE_URL=http://127.0.0.1:5185`, `AI_SERVICE_API_KEY` и обычный `AI_SERVICE_URL`. Локальный frontend: `VITE_LOCAL_AVATAR=1`, порт 5173. Разрешены только origin `http://localhost:5173` и `http://127.0.0.1:5173`.

Не запускайте одновременно другой Kit из той же установки. Node-код можно проверить отдельно без GPU: `npm test`. Тесты используют синтетический звук; лицевую анимацию и физический микрофон необходимо отдельно проверять на работающей платформе.

## Проверка

Локальная платформа проверялась с реальными OpenAI/A2F: речь, меняющиеся лицевые веса, остановка, смена лекции, повторная озвучка и mobile. Настройки путей в этой копии пакета проверяются отдельно; это не подтверждение нового развёртывания Kit или работы на сервере. Удачная сборка и тесты не подтверждают художественную естественность жестов.
