# Практика «Виртуальная лаборатория «Биометрия»» (`biometric_lab@1.0.0`)

Практика встраивает внешнюю учебную лабораторию по биометрии (отпечатки пальцев, лицо, радужка, голос) во встроенное окно страницы практики.
После работы студент проходит общую самопроверку по критериям. Оценка - самооценка, как у остальных практик: сервер платформы не получает данных из
лаборатории и не доверяет им.

## Настройки задания

`PUT items/{short_id}/practice/draft/`:

```json
{
  "practice_type": "biometric_lab",
  "plugin_version": "1.0.0",
  "title": "Лабораторная работа: распознавание отпечатков",
  "description": "Сравните два отпечатка в лаборатории.",
  "config": {
    "instructions": ["{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Сравните два отпечатка и объясните результат.\"}]}]}"],
    "criteria": [{"title": "Сравнены два образца", "description": "", "is_required": true}],
    "lab_url": "https://lab.example.org/",
    "lab_language": "kk"
  }
}
```

- `lab_url` обязателен: HTTPS без логина и пароля (для разработки допустим `http://localhost` и адреса 127.x.x.x).
- `lab_language` необязателен (`ru`, `kk`, `en`); без него язык лаборатории совпадает с языком платформы.
- Данные отправки: `{"checks": [true, ...], "lab_opened": true, "note": "до 2000 символов"}`.

## Где запустить лабораторию

Лаборатория - отдельный сервис (FastAPI), репозиторий проекта «Виртуальная лаборатория «Биометрия»». Docker не обязателен:

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Рекомендации для встраивания:

- Адрес с HTTPS на **поддомене платформы** (например, `lab.<домен платформы>`): cookie лаборатории (сессия и язык) тогда не блокируются как сторонние.
- Переменные лаборатории: `COOKIE_SECURE=true` за HTTPS; `SUBJECT_HEADER` - имя заголовка, в котором прокси передаёт ID пользователя платформы;
  один процесс (загрузки, обучение и счётчики хранятся в памяти процесса).
- Лаборатория не запрещает встраивание в iframe. Если нужно разрешить его только платформе, добавьте на прокси заголовок
  `Content-Security-Policy: frame-ancestors https://<домен платформы>`.
- Микрофон (голосовая биометрия) работает во встроенном окне, потому что страница практики выдаёт `allow="microphone"`.
